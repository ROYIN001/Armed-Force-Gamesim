# คลื่นมรกต — ต้นแบบเกมฝึกร่วม v0.1 (ซอร์สโค้ด)

หน้าเว็บเกมหน้าเดียว ไม่มี dependency ภายนอก (ยกเว้น Google Fonts)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `src/sim.js` | แกนจำลองทั้งหมด ไม่ใช้ DOM: แผนที่สมมติ, หน่วย, ข้าศึก, ภารกิจยิง, CAS, เรือ/เฮลิคอปเตอร์, พลเรือน, ระบบการตัดสินใจ (`DEC`) และ AI ที่เติมตำแหน่งว่าง |
| `src/render.js` | วาดแผนที่ด้วย canvas 2D (ใช้ทั้งตอนเล่นและตอนเล่นซ้ำใน AAR) |
| `src/ui.js` | หน้าจอทั้งหมด: หน้าแรก, ล็อบบี้ ORBAT, เกม, แผ่นตัดสินใจ, แผงผู้ฝึก, มินิเกมลงจอด, AAR, หน้าสมมติฐาน |
| `src/style.css` | ธีมมืดแบบห้องปฏิบัติการ |
| `src/shell.html` | โครง HTML ที่มีจุดแทรก `/*CSS*/ /*SIM*/ /*RENDER*/ /*UI*/` |
| `build.py` | รวมทุกไฟล์เป็น `dist/index.html` |
| `test/test_sim.js` | ทดสอบแกนจำลองใน Node (AI ล้วน, ทุกตำแหน่งแบบหมดเวลา/ตอบสุ่ม, ใส่สถานการณ์, บันทึก/โหลด JSON) |
| `test/smoke.py` | ทดสอบหน้าเว็บด้วย Playwright + Chrome (ตั้งตำแหน่ง Chrome ด้วยตัวแปร `CHROME_PATH`) |
| `dist/index.html` | ไฟล์ที่ build แล้ว เปิดในเบราว์เซอร์ได้ทันที |

## คำสั่ง

```bash
python3 build.py          # สร้าง dist/index.html
node test/test_sim.js     # ทดสอบแกนจำลอง (เพิ่ม verbose เพื่อดูรายละเอียด)
python3 test/smoke.py     # ทดสอบหน้าเว็บ (ต้องมี playwright)
```

## จุดเชื่อมหลักของ `sim.js`

- `SIM.newGame({seed, seat})` สร้างสถานะเกม (เป็น JSON ล้วน บันทึก/โหลดได้)
- `SIM.step(G, วินาทีในเกม)` เดินเวลา ทีละ 1 วินาที
- `G.pend` คือการตัดสินใจที่รออยู่ · `SIM.decide(G, id, k)` ตอบ
- `SIM.act(G, ชนิด, ค่า)` คำสั่งจากผู้เล่น (`cff`, `report`, `checkfire`, `helm`, `comm`, `artyhold`, `cav`)
- `SIM.inject(G, ชนิด)` ผู้ฝึกใส่สถานการณ์
- `SIM.summary(G)` สรุปผลสำหรับ AAR · `G.snaps` ภาพสถานะทุก 30 วินาทีสำหรับเล่นซ้ำ

ค่าตัวเลขทุกค่าในโค้ดเป็นค่าสาธิตเพื่อออกแบบเกม ไม่ใช่ข้อมูลอาวุธหรือหลักนิยมจริง
